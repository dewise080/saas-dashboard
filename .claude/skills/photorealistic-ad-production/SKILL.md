# Runs It All Photorealistic Ad Production

Use this skill after a concept and art direction are approved.

## Why this exists
Single-pass “generate the whole ad” workflows created visible AI artifacts: fake phones, synthetic screens, repetitive AI faces, glowing interface cards, distorted text, over-designed layouts, and unrealistic commercial scenes.

The fix is separation of concerns.

## Stage 1 — Clean photographic plate
Produce only the hero image.

Requirements:
- should look like a professional commercial photograph
- realistic person, hands, tools, phone, interior, materials and lighting
- no logo
- no headline
- no CTA
- no product feature icons
- no generated WhatsApp conversation
- no futuristic overlay
- deliberate negative space reserved for copy

Audit this image before proceeding.

## Stage 2 — Brand composition
Add:
- canonical Runs It All logo
- Inter typography
- approved evergreen/bone/brass system
- one headline
- one proof element if required
- one CTA
- minimal free-trial reassurance

When a phone screen carries meaningful product proof, use a controlled UI composite rather than generative text.

## Stage 3 — Reference comparison
Compare side by side against the approved Runs It All baseline.

Reject if the new work is:
- more synthetic
- more cluttered
- more “AI SaaS”
- less believable
- less premium
- less strategically branded

## Stage 4 — Final QA
The Photorealism Production Director and Realism/Visual QA Director must both pass the work before the Creative Challenger sees it.

## Anti-Bottleneck Production Rules

Creative should not stall on repeated decisions.

For each approved concept:
1. Create 3 clean photographic plates maximum.
2. Reject obvious misses immediately.
3. Select 1 strongest plate.
4. Composite 1 primary ad.
5. Create at most 2 meaningful variants by changing one strategic variable.
6. Ship to testing.

Do not endlessly regenerate minor aesthetic variations.

### Fast rejection triggers
Reject immediately if:
- logo is invented or altered
- face/skin/hands look AI-generated
- device hardware is implausible
- phone UI is generated and carries critical proof
- headline requires more than a second to decode
- the composition needs a feature grid to explain itself
- the image is busier than the approved baseline
- the scene is beautiful but unrelated to the selling idea

### Source-of-truth priority
When instructions conflict, use this order:
1. explicit current owner instruction
2. approved creative baseline
3. photorealistic production skill
4. creative council
5. individual agent preference



## Rule
If realism and conversion conflict, simplify the ad rather than adding fake visual proof.
